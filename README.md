# Aroma & Crumb Café ☕🍰

A modern, responsive website for **Aroma & Crumb Café** — showcasing coffee, bakery treats, breakfast specials, online orders, and home delivery via WhatsApp.

## 🚀 Features

- **Responsive Design**: Built with Tailwind CSS and responsive layouts for mobile, tablet, and desktop.
- **Bilingual & Localization**: Hindi & English support with Google Fonts (Noto Sans Devanagari & Inter).
- **Interactive Sections**:
  - Menu & daily bakery specials
  - Customer reviews and testimonials
  - Direct WhatsApp order & inquiry integration
  - Interactive table booking & contact modal
- **Single Page Application**: Ready for instant hosting on GitHub Pages or any static web host.

## 💻 Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Font Awesome & Lucide Icons
- Vanilla JavaScript

## 🌐 Live Preview

You can open `index.html` directly in any web browser or host it with [GitHub Pages](https://pages.github.com/).
